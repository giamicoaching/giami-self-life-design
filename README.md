# 지아미 자기주도 생애설계

자신의 삶을 여러 영역에서 돌아보고, 지금 우선적으로 다루고 싶은 영역과 삶의 방향이 되는 가치를 직접 선택하여 목표와 첫 행동을 설계하는 자기주도 생애설계 프로그램입니다. 프로그램이 우선 삶의 영역이나 목표를 대신 정하지 않습니다.

## 주요 기능

- 9개 삶의 영역의 중요도와 만족도를 1~7로 표시하며, 현재 삶을 돌아보는 삶의 영역 평가입니다.
- 변화검토지수 `(중요도 − 1) × (7 − 만족도)`와 삶의 수레바퀴를 참고정보로 보여 줍니다.
- 우선 삶의 영역 1개를 직접 선택하고, 원하는 변화와 핵심 가치를 탐색합니다.
- 가치 후보 5개, 핵심 가치 2개, 목표 1개, 첫 행동 1개를 스스로 정합니다.
- 실행계획 문장을 만들고, 장애물·대안행동·도움 자원을 정리합니다.
- 작성 내용은 자동 저장되며, 이어하기와 새로 시작하기를 지원합니다.
- 종합 결과를 저장하고 인쇄(PDF)할 수 있습니다.

## 저작권·이용안내

- 개인은 본 프로그램을 무료로 이용할 수 있습니다.
- 코치와 강사는 코칭 및 교육 장면에서 출처를 표시한 뒤 무료로 활용할 수 있습니다.
- 출처 없는 복제·재배포와 프로그램 자체를 별도의 상품으로 판매하는 것은 허용되지 않습니다.
- 수정·재가공하여 배포하거나 상업적 서비스에 활용하려는 경우에는 저작자와 사전에 협의가 필요합니다.

## 설치방법

Node.js가 설치된 환경에서 프로젝트 폴더로 이동한 뒤 의존성을 설치합니다.

```bash
npm install
```

## 실행방법

개발 서버를 실행합니다.

```bash
npm run dev
```

브라우저에서 [http://localhost:5173](http://localhost:5173) 으로 접속합니다.

프로덕션 미리보기:

```bash
npm run build
npm run preview
```

미리보기는 기본적으로 [http://localhost:4173](http://localhost:4173) 입니다.

## 테스트 및 빌드 명령

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

## 저장 방식

- 현재 버전은 비로그인 기준으로 **이 브라우저의 localStorage만** 사용합니다. 저장 키는 `giami.lifeDesign.v1`입니다.
- 계정 로그인, 다른 기기 이어보기, 서버 저장은 아직 지원하지 않습니다.
- 선택값은 즉시, 서술형은 입력 중 디바운스(400ms)로 자동 저장되며 탭을 숨기거나 창을 닫을 때도 저장합니다.
- 저장 계층은 이후 로그인 시 **Supabase 등 계정 저장소로 연동**할 수 있도록 `StorageAdapter`와 `mergeGuestIntoAccount`를 갖추었습니다.
